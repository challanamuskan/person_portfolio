## Features

- Netflix-inspired dark UI with red accent theme
- Fully responsive — mobile, tablet, desktop
- Built-in AI chatbot (Jerry) — rule-based, no API key needed
- Sections: Projects · Experience · Achievements · Certifications · Education · Skills · Volunteering
- Hero stats bar with live metrics visible on load
- Direct links to live projects and GitHub repos

## Run Locally

```bash
git clone https://github.com/challanamuskan/person_portfolio
cd person_portfolio
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

```bash
npm run build    # production build
npm run preview  # preview build locally
```
